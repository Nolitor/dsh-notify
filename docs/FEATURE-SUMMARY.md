## 1. 기능 설명
`dsh-notify`는 DSH 엔진의 턴 상태를 브라우저 네이티브 알림으로 전환하여, 사용자가 브라우저를 직접 보고 있지 않아도 작업 상태를 추적할 수 있도록 지원합니다.

- **작업 이벤트**: 턴 시작/완료/에러/질문/승인 대기 상태를 실시간 감지.
- **상태 그룹핑**: 세션별 쿨다운을 통해 반복되는 이벤트를 지능적으로 병합.
- **크로스 플랫폼 최적화**: 
    - Windows: 네이티브 앱 연동 알림 유지
    - macOS: OS 특성에 맞는 알림 처리
    - Linux: 권한 기반 폴백 UI(Toast) 지원
